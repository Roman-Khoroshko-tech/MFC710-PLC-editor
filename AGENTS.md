# Робота з редактором MFC710

- Цей репозиторій незалежний від головного порталу та інших інструментів.
- Змінюй вихідні файли dist/, потім запускай npm test, npm run build і npm run check:pages. Не правити тільки згенеровані HTML.
- Зберігай функції експорту JSON/CSV і локальне автозбереження без відправлення проєктів на сервер.
- Не додавай аналітику, зовнішні CDN, конфіденційні проєкти або токени.
- Підтримуй посилання portal-home на https://roman-khoroshko-tech.github.io/. Не роби запуск редактора залежним від порталу.
- Технічні параметри підтверджуй наявними джерелами; не змінюй логіку PLC під виглядом редизайну.
- Для критичних змін – гілка, PR, успішний CI й браузерні тести до merge. Браузерні тести потребують Playwright; відсутність запуску зазначай прямо.
- Перевіряй українську/англійську/польську локалізації та відносні шляхи GitHub Pages.
- Зберігай THIRD_PARTY_NOTICES.md. Не змінюй ліцензійні умови виробника.
- Відкат через git revert, без force push; після відкату перевір згенеровану Pages-версію.
